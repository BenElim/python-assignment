# Python Assignment

This folder contains a password generator and a small example of importing functions from your own Python module.

## Password Generator

Run the generator with:

```powershell
python password_generator.py
```

It prints a random 8-character password and a random 12-character password, along with their lengths. Run it again to generate new passwords.

## Your Own Module

Run the importing script:

```powershell
python main.py
```

Expected output:

```text
Welcome to PLP, Amina!
8
4
```

Run the helper module on its own:

```powershell
python helpers.py
```

Expected output:

```text
3
```
